# battery-tray

Іконки в треї Windows із відсотком заряду бездротових пристроїв — окрема іконка на кожен пристрій.

Підтримується:
- **Bluetooth** — усе, для чого Windows сама показує заряд у «Параметри → Bluetooth і пристрої».
- **Logitech через USB-донгл** (Lightspeed / Unifying / Bolt) — протокол HID++ 2.0.

## Збірка

```powershell
.\build.ps1    # → dist\battery-tray.exe, один файл, Python на машині не потрібен
```

Покладіть exe у постійне місце (наприклад `%LOCALAPPDATA%\Programs\battery-tray\`) і запустіть.
Автозапуск вмикається в налаштуваннях або в меню іконки й запам'ятовує поточний шлях до exe:
після переміщення файлу його треба ввімкнути ще раз.

## Запуск із вихідного коду

```powershell
.\.venv\Scripts\pythonw.exe -m battery_tray          # у треї, без консолі
.\.venv\Scripts\python.exe  -m battery_tray --once   # надрукувати знайдені пристрої й вийти
```

Автозапуск у цьому режимі недоступний — він є лише в зібраному exe.

Клік по іконці відкриває вікно зі списком усіх знайдених пристроїв, зокрема не підключених зараз.
Клік по пристрою відкриває його сторінку: назва, показ у треї, іконка типу (визначається автоматично,
можна змінити) і власні значення замість типових. Типові значення — у розділі «Налаштування».
Пристрої з однаковою назвою показуються однією іконкою. Зміни зберігаються одразу.

Іконка в треї — значок типу пристрою і вертикальна батарея праворуч; рівень заряду видно з її заповнення.
Колір заповнення: червоний — мало, оранжевий — середньо, білий (чорний на світлій панелі) — у нормі,
зелений — заряджається. Обидва пороги задаються повзунком із кроком 5% — типово для всіх і окремо для пристрою.
Відключений пристрій ще кілька хвилин показується так само, як підключений.
Точний відсоток — у підказці іконки та у вікні.

Окрім іконок пристроїв, у треї завжди є іконка самої програми. Іконку пристрою можна показувати завжди
або лише коли його батарея червона чи червона або оранжева — типово для всіх і окремо для кожного пристрою.

- Налаштування: `%APPDATA%\battery-tray\settings.json`
- Лог: `%LOCALAPPDATA%\battery-tray\battery-tray.log`
